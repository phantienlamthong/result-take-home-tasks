# AI Journey

AI was used as an engineering assistant during the take-home task.

The AI was primarily used for:

- understanding the existing project structure
- identifying Windows coupling
- reviewing .NET project dependencies
- reasoning about Docker containerization
- reviewing Kubernetes and Helm configuration
- troubleshooting build and deployment errors
- reviewing the final implementation and documentation

AI output was treated as advisory rather than authoritative.

All generated suggestions were validated against the repository,
compiler/build output, Docker runtime behavior, Kubernetes state,
and application endpoints.
